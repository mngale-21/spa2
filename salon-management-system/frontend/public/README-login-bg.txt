Login page background image
============================

Drop an image file named exactly:

    login-bg.jpg

into this folder (frontend/public/) and the login page will use it
automatically as a full-page background, behind the existing gold/terracotta
glow and a dark wash — so the sign-in card stays fully readable regardless
of the photo. No code changes needed.

Recommended: a wide, moody/dark photo (salon interior, decor, texture),
at least 1920px wide.

If no login-bg.jpg is present, the login page looks exactly as it did
before (plain dark background + glow) — nothing breaks.

Safe to delete this note once login-bg.jpg is in place.
